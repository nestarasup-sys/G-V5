# F09.15 — prévia composta do catálogo facial

## Implementação

- O workspace facial monta uma `RenderScene` com a revisão publicada do modelo e as seleções faciais visíveis padrão do catálogo.
- `FaceCatalogPreviewRenderer` busca e decodifica dimensões dos assets faciais no `IAssetStore`, usa o `FaceCatalogPreviewSceneBuilder` e renderiza pela mesma interface `IRenderSceneRenderer` usada pelo Fabricador.
- A imagem resultante aparece dentro do painel facial. A troca de catálogo/modelo atualiza o frame; cancelamento descarta renders obsoletos, e o ViewModel/controle descartam os bitmaps que possuem.
- O cache local de recortes do preview tem limite de 64 assets. A decodificação continua sujeita aos limites centrais de `AssetImageDecoder`.
- Falhas de asset ou renderização deixam uma mensagem no painel em vez de exibir uma composição parcial como se estivesse correta.

## Evidência

- `FaceWorkspaceViewModelTests.ComposedPreviewScene_UsesDecodedComponentBoundsAndOnlyDefaultVisibleSelections` importa uma imagem PNG sintética pelo `IAssetStore`, constrói um catálogo com duas sobrancelhas, verifica a dimensão renderizada, as três camadas da cena e os recortes obtidos pela decodificação real.
- `cmd.exe /c TestarLocal.bat rapido` passou localmente em Debug: build da solution sem avisos/erros; 331 testes aprovados, 0 falhas, incluindo 78 headless.
- `git diff --check` passou antes do commit.
