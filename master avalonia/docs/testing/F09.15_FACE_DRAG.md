# F09.15 — arraste de componente facial na prévia

## Comportamento implementado

- A prévia composta aceita arraste com o botão esquerdo para mover o componente selecionado no catálogo.
- O deslocamento da tela é convertido para unidades do modelo, respeitando o ajuste `Uniform` e a escala do render de prévia; o eixo vertical é convertido de tela para o Y-up do modelo.
- Durante o gesto, os campos X/Y e a cena temporária acompanham o ponteiro. Movimentos intermediários não gravam revisões no catálogo.
- Ao soltar, o workspace aplica a transformação uma vez pelo repositório existente, criando uma única revisão. Cancelar a captura restaura os campos e a prévia sem persistir.
- Um clique sem deslocamento não cria uma revisão. Movimento não finito ou além dos limites é recusado.

## Limites

O teste headless valida o fluxo do ViewModel e o gesto não foi executado com mouse físico no Windows. DPI, captura real, sensação do arrasto e alinhamento visual continuam pendentes para a revisão final. O gesto move o componente previamente selecionado; não faz seleção por pixel-hit-test dentro da imagem.
