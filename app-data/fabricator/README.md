# Backup dos dados locais do Fabricador

Esta pasta contém uma cópia dos dados de usuário do Fabricador no momento em que foi publicada: modelos, poses, roupas, imagens e histórico de edição.

O app continua usando a pasta de dados do Electron em `%APPDATA%\\gacha-nymi-work-app\\fabricator`. Esta cópia no repositório serve como backup e material para reproduzir o problema de encaixe; ela não é carregada automaticamente pelo app.
